## 一、学习内容记录

Linux 命令由命令名、选项和参数组成。命令名说明要执行的操作；选项通常以 `-` 或 `--` 开头，用于改变命令行为；参数表示命令处理的文件、目录或其他对象。例如，`ls -l /home` 中，`ls` 为命令名，`-l` 为选项，`/home` 为参数。

本次学习并实践了目录查看与切换命令（`ls`、`pwd`、`cd`），登录与帮助查询命令（`who`、`man`、`whereis`、`which`），文件查找与文本检索命令（`find`、`locate`、`grep`），以及文本和二进制处理命令（`echo`、`od`、`sort`）。另外还了解了文件管理、磁盘管理、进程管理、用户管理、网络管理和压缩解压等常用命令类别。

依次实践了 `ls`、`ls -l`、`ls -a`、`ls -lh`、`ls /root`、`ls -t` 和 `ls -R`。前四项和按时间排序、递归列出目录均成功。`ls /root` 失败，终端提示 `Permission denied`，因为当前使用的是普通用户，默认没有读取 root 用户家目录的权限；如确有管理需要，应在确认权限范围后使用 `sudo ls /root`。

### 7. grep：检索文本内容

### 9. od：以不同格式查看文件内容

实践了 `od -c test.bin`、`od -x test.bin`、`od -t d test.bin`、`od -A x test.bin` 和 `od -i a.out`。这些命令均因目标文件不存在而失败，提示 `No such file or directory`。`locate test.bin` 找到的是其他位置的同名文件，并不在当前工作目录，因此不能直接作为 `od` 的参数。后续可先创建测试文件，例如 `printf 'ABC' > test.bin`，再执行 `od -c test.bin`；`a.out` 则需要先编译 C 程序生成。

## 三、问题记录与改进建议

1. 题目中“`which cd` 会显示对应信息”的表述不够准确。`cd` 是 Shell 内建命令，`which` 通常不会显示路径；使用 `type cd` 更合适。
2. `od` 和 `sort` 的示例依赖 `test.bin`、`a.out`、`names.txt`、`numbers.txt`、`data.txt` 等前置文件。练习说明应同时给出创建这些文件的步骤，避免把“文件不存在”误判为命令本身错误。
3. 在普通用户环境中，`ls /root` 与递归 `grep /etc` 出现权限不足是正常安全机制。应先理解权限边界，再在有明确授权时使用 `sudo`，不能为了消除报错而随意提升权限。
4. WSL 环境与完整 Linux 服务器存在差异，例如 `who` 可能显示 0 个登录用户，`man` 页面也可能因精简安装而缺少依赖。遇到这类情况应结合系统环境判断，不应只按预期输出判断成败。
